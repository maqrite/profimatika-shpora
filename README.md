# Супершпора ЕГЭ — рабочее пространство

Шпора состоит из двух книг: **теории** (темы в логическом порядке) и **практики** (разборы прототипов по номерам заданий).
Есть и однокнижная версия из двух частей. Книги связаны кодами тем (`Ч1.3`, `А1.2`, …) и разборов (`Р11-01`, …).
Каждая ссылка кликабельна и показывает номер страницы.

**Главное правило:** структура живёт в Google-таблице, а текст — в `.tex`-файлах.
Названия тем, порядок глав, строки «Опирается на» и «Где встречается», оглавления и указатель генерируются сами.
Руками пишется только содержимое тем, разборов и рисунков.

## Что где лежит

```
shpora/
├── teoriya.tex  praktika.tex     две отдельные книги
├── shpora.tex                    одна книга: часть 1 + часть 2 (основной файл для Overleaf)
├── pilot.tex                     пилот: только главы Ч1 и А1
├── vvedenie/                     оглавление, «Как пользоваться шпорой», указатель, порядок частей
│
├── teoriya/<буква>/<код>.tex     ТЕМЫ — по файлу на тему (Ч1.3 → teoriya/Ch/Ch1-3.tex)
├── praktika/<код>.tex            РАЗБОРЫ — по файлу на разбор (Р11-01 → praktika/R11-01.tex)
├── risunki/
│   ├── src/<код>_<N>.tex         исходники рисунков (A1-2_1.tex — 1-й рисунок темы А1.2)
│   ├── build/                    готовые PDF рисунков (собираются сами)
│   ├── preamble.tex              общая шапка рисунков
│   └── _shablon_risunka.tex      шаблон нового рисунка
├── stil/
│   ├── shpora.sty                вёрстка: формат, плашки, ссылки, оглавления
│   └── profig.sty                набор для рисунков: палитра, стили линий, отметки
├── shrifty/                      Fira Sans + Fira Math (лежат в проекте, ставить ничего не нужно)
├── dannye/                       выгрузка таблицы: temy.csv, razbory.csv, svyazi.csv
├── sgenerirovano/                служебное, генерируется — руками НЕ править
├── instrumenty/
│   ├── obnovit_iz_tablicy.py     скачать листы из Google-таблицы в dannye/
│   ├── generate.py               таблица → sgenerirovano/ + заготовки новых тем
│   └── sobrat.sh                 полная сборка всех книг
├── sborka/                       промежуточные файлы LaTeX (мусор, можно удалять)
└── vypusk/                       готовые PDF
```

Буквы разделов в именах файлов: Ч→Ch, А→A, Т→T, Ф→F, Д→D, П→P, К→K, С→S, В→V, М→M, Р→R.
Точка в коде заменяется дефисом.

## Как работать

### 1. Обновить структуру из таблицы

Темы, связи и разборы ведутся в Google-таблице. Чтобы подтянуть изменения:

```bash
python3 instrumenty/obnovit_iz_tablicy.py
```

Скрипт работает, если у таблицы включён доступ «Все, у кого есть ссылка — читатель».
Если доступа по ссылке нет, листы «Темы», «Разборы» и «Связи» скачиваются вручную через «Файл → Скачать → CSV».
Их нужно положить в `dannye/` как `temy.csv`, `razbory.csv` и `svyazi.csv`.

Что берётся из таблицы:

| Лист | Что влияет на книгу |
|---|---|
| Темы | код, название, глава, «Опирается на», «Задание ЕГЭ-2027», «Порядок в шпоре» (порядок глав) |
| Разборы | код, номер задания, тип (заголовок разбора) |
| Связи | «ключевая» → строка «Понадобится», «вспомогательная» → «ещё пригодится»; обратная строка «Где встречается» у темы |

Строки, в описании которых есть слово «ПРИМЕР», пропускаются.

### 2. Собрать

```bash
./instrumenty/sobrat.sh            # все книги: teoriya, praktika, shpora, pilot
./instrumenty/sobrat.sh pilot      # только одну
```

Скрипт сам запускает генератор, пересобирает только изменённые рисунки и прогоняет LaTeX нужное число раз.
Готовые PDF появляются в `vypusk/`.

Нужен TeX Live с XeLaTeX (на Mac — MacTeX, на Windows — TeX Live или MiKTeX + Git Bash).

### 3. Написать тему

Новая строка в таблице → после сборки появляется файл-заготовка (в книге он виден как серая рамка «заготовка»).
Уже написанные файлы генератор **никогда не перезаписывает**.

```latex
\begin{tema}{А1.2}                     % заголовок, «Опирается на», «Где встречается» — сами
\opr{Модуль} числа — …                 % выделенный термин
\[ |a| = \begin{cases} … \end{cases} \]

\begin{primer}                         % «Пример.» — синяя полоска
$|x-2|\leqslant 3 \iff x\in[-1;\,5]$.
\end{primer}

\begin{oshibka}                        % «Частая ошибка.» — оранжевая полоска
…
\end{oshibka}

\risunok[0.62]{A1-2_1}                 % рисунок из risunki/build, 0.62 — доля ширины
Подробнее — \tref{Ч1.3}.               % ссылка на тему: код + страница, кликабельно
\end{tema}
```

Ссылки:
- `\tref{Ч1.3}` — на тему;
- `\rref{Р11-01}` — на разбор;
- `\trefk{Ч1.3}` — только код, без страницы.

Если объект лежит в другой книге, номер страницы берётся из неё («Р11-01 практика, с. 3»).
Если объекта в сборке нет (например, в пилоте), выводится просто код.

**Тема не разрывается между страницами.** Если тема не влезает на остаток страницы, она целиком переезжает на следующую.

**Если тема длиннее страницы**, она переносится сама. Тема начинается на текущей странице, если там свободно больше половины, иначе — с новой.
На продолжении повторяется заголовок с пометкой «(продолжение)», а внизу первой части стоит «продолжение на следующей странице →».
В конце сборки `sobrat.sh` выводит список таких тем. Правило: длинная тема — повод подумать, не разбить ли её на две в таблице.

Другие полезные команды:
- `\nomer{3}` — номер формулы справа;
- `\pfChip{текст}` — плашка.

### Таблицы

Все таблицы оформляются одной средой. Получается шапка, «зебра» и скруглённая рамка:

```latex
\begin{pfTablica}{lll}                 % столбцы как в обычной tabular: l c r
Длина & Площадь & Объём\\              % первая строка — шапка
$1$ км $=1000$ м & … & …\\
\pfItog Итого & … & …\\                % \pfItog — жирная итоговая строка
\end{pfTablica}
```

- `[bez shapki]` — без шапки, только «зебра» (для списков формул и свойств).
- `[levo]` — прижать таблицу влево.
- `\pfPodshapka{Разности степеней}\\` — строка-подзаголовок на всю ширину, число столбцов считается само.
- `\Block[l]{2-1}{…}` — объединить ячейки (2 строки × 1 столбец).
- Схема Горнера: `\pfGorner{3}{1 & -2 & 5 & -24}{1 & 1 & 8}{0}` — корень, коэффициенты, получившиеся числа, остаток.

`\toprule`, `\hline` и вертикальные линии не нужны — оформление делает среда.

### 4. Написать разбор

```latex
\begin{razbor}{Р11-01}                 % заголовок и «Понадобится: …» — из таблицы
\Uslovie …
\Reshenie … (\tref{Ч1.3}) …
\Otvet{20.}
\end{razbor}
```

Разбор, в отличие от темы, может переходить на следующую страницу.

### 5. Нарисовать рисунок

1. Скопировать `risunki/_shablon_risunka.tex` в `risunki/src/` и назвать по коду темы: `P5-2_1.tex`, `P5-2_2.tex`, …
2. Поправить координаты точек и выбрать роли линий. Цвета и толщины задавать не нужно — они в стилях:

| Стиль | Цвет | Для чего |
|---|---|---|
| `given` | чёрный | данные фигуры |
| `main` | синий | главное построение |
| `find` | оранжевый | искомое |
| `accent` | фиолетовый | второе важное |
| `aux` | фиолетовый пунктир | вспомогательные линии |
| `extra` | зелёный | только в крайнем случае |

   Отметки и подписи:
   - `tick1`/`tick2`/`tick3` — равные отрезки;
   - `ang1`, `\pfAngTwo{A}{B}{C}{3}` — равные углы;
   - `rightang` — прямой угол;
   - `\pfPoint{A}{A}{below left}` — точка с подписью.

   Графики строятся через `\begin{axis}[pfaxis]` и стили `pfgraph`/`pftan`.
3. Вставить рисунок в тему командой `\risunok{P5-2_1}`.

Пока рисунка нет, в книге стоит пунктирная рамка с его именем, поэтому место под рисунок можно разметить заранее.

Готовые образцы лежат в `risunki/src/`: треугольник, окружность, график, числовая прямая.

## Оформление и бренд

Оформление «Клетка» целиком описано в `stil/oformlenie.tex`: колонтитулы, плашки тем и разборов, начала глав, разделители частей и оглавление.
Всё фирменное собрано в `stil/brend.sty`: цвета, шрифт Montserrat для заголовков и колонтитулов, ссылки на сайт, курс и соцсети.

| Что | Где | Как заменить |
|---|---|---|
| Обложка | `stil/brend/oblozhka.png` | положить новую картинку с тем же именем (пропорции 150×212) |
| Словесный знак «профиматика» | `stil/brend/logo-slovo-path.tex` (временный) | положить оригинал как `stil/brend/logo-slovo.pdf` |
| Буква φ | там же (временная) | положить оригинал как `stil/brend/logo-fi.pdf` |
| Иконки соцсетей | `stil/brend/ikonki.tex` (Simple Icons, CC0) | — |

Если в `stil/brend/` лежат `logo-slovo.pdf` или `logo-fi.pdf`, они подхватятся вместо временных.

QR-коды на обложке кликабельные: ведут в ВК, YouTube и Telegram.

Вкладка на правом краю страницы показывает раздел (у теории — голубая, у практики — фиолетовая) и ведёт к началу главы.

## Overleaf

1. Загрузить zip проекта целиком (New Project → Upload Project).
2. Menu → Compiler: **XeLaTeX**; Main document: `shpora.tex` (или `pilot.tex`).
3. Рисунки Overleaf сам не собирает. Нужно либо собрать их локально (`sobrat.sh`) и загрузить `risunki/build/*.pdf`, либо скомпилировать нужный `risunki/src/*.tex` как главный документ и скачать PDF в `risunki/build/`.
4. После правок таблицы генератор нужно запустить локально и обновить `sgenerirovano/`: Overleaf не запускает Python.
5. Номера страниц *между двумя отдельными книгами* корректно получаются только при локальной сборке.
   В однокнижной `shpora.tex` всё работает и на Overleaf.

Русские переносы: на Overleaf они есть.
При локальной сборке без русских шаблонов переносов (`texlive-lang-cyrillic`) текст собирается, но без переносов.
