# Супершпора ЕГЭ — рабочее пространство

Шпора — одна книга из двух частей: **теория** (темы в логическом порядке) и **практика** (разборы прототипов по номерам заданий).
Части связаны кодами тем (`Ч1.3`, `А1.2`, …) и разборов (`Р11-01`, …).
Каждая ссылка кликабельна и показывает номер страницы.

**Главное правило:** структура живёт в Google-таблице, а текст — в `.tex`-файлах.
Названия тем, порядок глав, строки «Опирается на» и «Где встречается», оглавления и указатель генерируются сами.
Руками пишется только содержимое тем, разборов и рисунков.

Файл темы называется её кодом: `Ч1.3.tex`, разбор — `Р11-01.tex`, рисунок — `код_номер`: `А1.2_1`.

## Как работать

### 1. Обновить структуру из таблицы

Темы, связи и разборы ведутся в Google-таблице. Чтобы подтянуть изменения:

```bash
python3 инструменты/obnovit_iz_tablicy.py
```

Скрипт работает, если у таблицы включён доступ «Все, у кого есть ссылка — читатель».
Если доступа по ссылке нет, листы «Темы», «Разборы» и «Связи» скачиваются вручную через «Файл → Скачать → CSV».
Их нужно положить в `данные/` как `темы.csv`, `разборы.csv` и `связи.csv`.

Что берётся из таблицы:

| Лист | Что влияет на книгу |
|---|---|
| Темы | код, название, глава, «Опирается на», «Задание ЕГЭ-2027», «Порядок в шпоре» (порядок глав) |
| Типы | классификация заданий из [банка задач](https://bank-zadach.ru/tasks): код типа (`11.1`), задание, название, ссылка на задачи этого типа в банке |
| Разборы | код, задание, **тип** (код из листа «Типы», выбирается из списка), «Кратко» — заголовок разбора |
| Связи | «ключевая» → строка «Понадобится», «вспомогательная» → «ещё пригодится»; из ключевых связей собирается «Где встречается» у темы |

Строки, в описании которых есть слово «ПРИМЕР», пропускаются.

**Как устроена практика.** Задание делится на типы по классификации банка задач Профиматики, разборы лежат внутри своего типа:
- в начале задания — плашка со всеми типами: у каждого страница разбора (если он уже есть) и ссылка на задачи этого типа в банке;
- у каждого типа — полоса с названием и ссылкой «задачи с разборами в банке ↗».

**«Где встречается» у темы** — список типов, а не отдельных задач: «№ 11 — Концентрация, с. 16 · № 13 — Кредиты».
Типы берутся из ключевых связей темы с разборами. Каждый тип кликабелен и ведёт в свой раздел практики.

Если в банке появились новые типы, лист «Типы» нужно обновить. Новый тип добавляется в конец своего задания со следующим кодом: в задании 11 после `11.8` идёт `11.9`. Коды уже существующих типов не меняются.

### 2. Собрать

```bash
./инструменты/sobrat.sh            # шпора и пилот
./инструменты/sobrat.sh пилот      # только одну
```

Скрипт сам запускает генератор, пересобирает только изменённые рисунки и прогоняет LaTeX нужное число раз.
Готовые PDF появляются в `выпуск/`.

Нужен TeX Live с XeLaTeX (на Mac — MacTeX, на Windows — TeX Live или MiKTeX + Git Bash).

### 3. Написать тему

**Сначала — материалы и стиль.** Перед тем как писать тему, открой её материалы: лист «Материалы» в Google-таблице, колонка «Главы шпоры» (копия — `данные/материалы.csv`). Это вычитанные методички и шпаргалки Профиматики, текст оттуда можно брать.
Как формулировать определения, правила, алгоритмы и примеры — в [`стиль-изложения.md`](стиль-изложения.md).


Новая строка в таблице → после сборки появляется файл-заготовка (в книге он виден как серая рамка «заготовка»).
Уже написанные файлы генератор **никогда не перезаписывает**.

```latex
\begin{tema}{А1.2}                     % заголовок, «Опирается на», «Где встречается» — сами
\opr{Модуль} числа — …                 % выделенный термин
\[ |a| = \begin{cases} … \end{cases} \]

\begin{primer}                         % «Пример.» — синяя полоска
$|x-2|\leqslant 3 \iff x\in[-1;\,5]$.
\end{primer}

\begin{oshibka}                        % «Частая ошибка.» — оранжевая полоска
…
\end{oshibka}

\risunok[0.62]{А1.2_1}                 % рисунок из рисунки/готовые, 0.62 — доля ширины
Подробнее — \tref{Ч1.3}.               % ссылка на тему: код + страница, кликабельно
\end{tema}
```

Ссылки:
- `\tref{Ч1.3}` — на тему;
- `\rref{Р11-01}` — на разбор;
- `\trefk{Ч1.3}` — только код, без страницы.

Если объекта в сборке нет (например, в пилоте), выводится просто код.

**Тема не разрывается между страницами.** Если тема не влезает на остаток страницы, она целиком переезжает на следующую.

**Если тема длиннее страницы**, она переносится сама. Тема начинается на текущей странице, если там свободно больше половины, иначе — с новой.
На продолжении повторяется заголовок с пометкой «(продолжение)», а внизу первой части стоит «продолжение на следующей странице →».
В конце сборки `sobrat.sh` выводит список таких тем. Правило: длинная тема — повод подумать, не разбить ли её на две в таблице.

**Начало главы.** Над первой темой главы стоит большая плашка с названием главы. Если первая тема под неё не влезает, плашка автоматически становится компактной полоской в одну строку, чтобы не остаться одной на пустой странице.

**Раздел «Задания ЕГЭ → темы»** стоит в самом конце книги, после практики. Он собирается из столбца «Задание ЕГЭ-2027» листа «Темы». В начале — список всех заданий; по каждому заданию — главы и все нужные темы с названиями и страницами. Строка «Какие темы повторить к заданию N» на плашке задания в практике ведёт в блок этого задания.

**Номера в строке «Задания ЕГЭ» под темой** ведут к разборам задания в практике. Если разборов задания ещё нет, номер серый и не кликается.

Ссылка «Задания ЕГЭ ↑» внизу каждой страницы ведёт к списку заданий. Поправили номера в таблице — раздел обновится при следующей сборке.

Другие полезные команды:
- `\nomer{3}` — номер формулы справа;
- `\pfChip{текст}` — плашка.

### Таблицы

Все таблицы оформляются одной средой. Получается шапка, «зебра» и скруглённая рамка:

```latex
\begin{pfTablica}{lll}                 % столбцы как в обычной tabular: l c r
Длина & Площадь & Объём\\              % первая строка — шапка
$1$ км $=1000$ м & … & …\\
\pfItog Итого & … & …\\                % \pfItog — жирная итоговая строка
\end{pfTablica}
```

- `[bez shapki]` — без шапки, только «зебра» (для списков формул и свойств).
- `[levo]` — прижать таблицу влево.
- `\pfPodshapka{Разности степеней}\\` — строка-подзаголовок на всю ширину, число столбцов считается само.
- `\Block[l]{2-1}{…}` — объединить ячейки (2 строки × 1 столбец).
- Схема Горнера: `\pfGorner{3}{1,-2,5,-24}` — корень и коэффициенты через запятую. Произведения, суммы, остаток и стрелки шпора считает и рисует сама.

`\toprule`, `\hline` и вертикальные линии не нужны — оформление делает среда.

### 4. Написать разбор

```latex
\begin{razbor}{Р11-01}                 % заголовок и «Понадобится: …» — из таблицы
\Uslovie …
\Reshenie … (\tref{Ч1.3}) …
\Otvet{20.}
\end{razbor}
```

Разбор, в отличие от темы, может переходить на следующую страницу.

### 5. Нарисовать рисунок

1. Скопировать `рисунки/_шаблон_рисунка.tex` в `рисунки/исходники/` и назвать по коду темы: `П5.2_1.tex`, `П5.2_2.tex`, …
2. Поправить координаты точек и выбрать роли линий. Цвета и толщины задавать не нужно — они в стилях:

| Стиль | Цвет | Для чего |
|---|---|---|
| `given` | чёрный | данные фигуры |
| `main` | синий | главное построение |
| `find` | оранжевый | искомое |
| `accent` | фиолетовый | второе важное |
| `aux` | фиолетовый пунктир | вспомогательные линии |
| `extra` | зелёный | только в крайнем случае |

   Отметки и подписи:
   - `tick1`/`tick2`/`tick3` — равные отрезки;
   - `ang1`, `\pfAngTwo{A}{B}{C}{3}` — равные углы;
   - `rightang` — прямой угол;
   - `\pfPoint{A}{A}{below left}` — точка с подписью.

   Графики строятся через `\begin{axis}[pfaxis]` и стили `pfgraph`/`pftan`.
3. Вставить рисунок в тему командой `\risunok{П5.2_1}`.

Пока рисунка нет, в книге стоит пунктирная рамка с его именем, поэтому место под рисунок можно разметить заранее.

Готовые образцы лежат в `рисунки/исходники/`: треугольник, окружность, график, числовая прямая.

## Оформление и бренд

Оформление «Клетка» целиком описано в `стиль/оформление.tex`: колонтитулы, плашки тем и разборов, начала глав, разделители частей и оглавление.
Всё фирменное собрано в `стиль/бренд.sty`: цвета, шрифты бренда (Unbounded — крупные надписи: «Теория», «Ч1», заголовки разделов, плашки-коды; Manrope — мелкие надписи колонтитулов), логотип, ссылки на сайт, курс и соцсети. Основной текст набран Manrope, формулы — Fira Math. У Manrope нет курсива, поэтому курсив — наклонённый прямой шрифт.

| Что | Где | Как заменить |
|---|---|---|
| Обложка | `стиль/бренд/обложка.png` | положить новую картинку с тем же именем (пропорции 150×212) |
| Словесный знак «профиматика» | `стиль/бренд/логотип.pdf` — вектор, обведён по присланному логотипу | положить новый PDF с тем же именем |
| Буква φ | `стиль/бренд/фи.pdf` (оттуда же) | положить новый PDF с тем же именем |
| Иконки соцсетей | `стиль/бренд/иконки.tex` (Simple Icons, CC0) | — |
| Кот «тык» внизу страницы | `стиль/бренд/кот-тык.png`, ссылка — `\pfVideoKot` в `стиль/бренд.sty` | положить новую картинку с тем же именем; размер иконок — `\pfRazmerIkonok` в `стиль/оформление.tex` |

Если `логотип.pdf` или `фи.pdf` удалить, вместо них нарисуется старый контур из `логотип-контур.tex`.

QR-коды на обложке кликабельные: ведут в ВК, YouTube и Telegram.

Вкладка на правом краю страницы показывает раздел (у теории — голубая, у практики — фиолетовая) и ведёт к началу главы.

## Overleaf

1. Загрузить zip проекта целиком (New Project → Upload Project).
2. Menu → Compiler: **XeLaTeX**; Main document: `шпора.tex` (или `пилот.tex`).
3. Рисунки Overleaf сам не собирает. Готовые PDF рисунков лежат в репозитории в `рисунки/готовые/`. Новый рисунок нужно собрать локально (`sobrat.sh`) или скомпилировать его `рисунки/исходники/*.tex` как главный документ и положить PDF в `рисунки/готовые/`.
4. После правок таблицы генератор нужно запустить локально и обновить `сгенерировано/`: Overleaf не запускает Python.

Русские переносы: на Overleaf они есть.
При локальной сборке без русских шаблонов переносов (`texlive-lang-cyrillic`) текст собирается, но без переносов.
